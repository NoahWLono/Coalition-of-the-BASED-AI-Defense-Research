Project 6: CEDAR portfolio / CLAIMS_LEDGER

Portfolio claims ledger

Scope: CEDAR 0.1.0, the bundled synthetic civilian inspection corpus, and the recorded local execution. Noah Weinberger supplied the direction and stated background. AI assistants generated and implemented the project, prepared annotations and performed the recorded checks. No customer, human annotator or independent auditor has validated these results.

Commands below run from the repository with the frozen environment. uv run --frozen python -m cedar verify runs the suite and evaluation. Test names are stable evidence pointers; the saved result is test-results.txt. The evaluation JSON records denominators, timestamps and resource observations.
