# CEDAR Implementation Plan

> **For agentic workers:** use the executing-plans workflow and focused delegated tasks. The user explicitly requests autonomous execution.

**Goal:** deliver the full local procurement workbench and defensible portfolio package.

**Architecture:** deterministic ingestion and policy/cost/scoring engines feed a SQLite revision store. FastAPI enforces sessions and role permissions. A plain browser UI reads the same evaluation exported in immutable decision records.

**Tech Stack:** Python 3.13.15 (project-local), FastAPI, uvicorn, SQLite, jsonschema, pytest, httpx2; plain JavaScript/CSS.

**Spec:** ../specs/2026-10-17-cedar-design.md and ../../CONTRACT.md

## Global constraints

Synthetic civilian data; six units; zero spending; no publication, vendor contact or aircraft connection; preserve unrelated work. Milestone A precedes B. Exact dataset counts: 12 packages, 40 requirements (18/14/8), 36 base documents, 3 amendments, 2 policy versions.

## Review focus

- Unknown units and contradictory assertions must not support a mandatory gate.
- Structured inputs and inventories must be bound into exported snapshot hashes.
- Rejected interpretations and expired evidence must remain inspectable.
- Racing review and input updates must never create a current approval over old inputs.
- Untrusted text must stay inert in UI, exports and filesystem handling.
